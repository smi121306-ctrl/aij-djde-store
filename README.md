# Aij Djde - Premium Apple Accessories Store

Модерн интернет-магазин премиальных аксессуаров для Apple, построенный на Next.js 14 с TypeScript.

## 🚀 Возможности

- ⚡ Next.js 14 для высокой производительности
- 🎨 Современный и адаптивный дизайн
- 📱 Полностью отзывчивый на мобильных устройствах
- 🛒 Система корзины товаров
- 💳 Готово к интеграции платежей
- 🌐 SEO оптимизировано

## 📋 Требования

- Node.js 18+ 
- npm или yarn

## 🔧 Установка

```bash
# Клонировать репозиторий
git clone https://github.com/smi121306-ctrl/aij-djde-store.git
cd aij-djde-store

# Установить зависимости
npm install

# Запустить dev сервер
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 📁 Структура проекта

```
.
├── app/
│   ├── layout.tsx         # Root layout
```

## 🎯 Основные компоненты

### Header
- Логотип и навигация
- Иконки (избранное, профиль, корзина)
- Адаптивное меню

### Hero Section
- Брендовое приветствие
- Описание компании
- CTA кнопка

### Products Grid
- Сетка товаров 3 колонки (адаптивная)
- Карточки товаров с ценой
- Функция добавления в корзину

### Footer
- Информационные ссылки
- Ссылки компании
- Контактная информация

## 🚀 Развертывание

## 📝 Доступные команды

- `npm run dev` - Запустить dev сервер
- `npm run build` - Создать production build
- `npm run start` - Запустить production сервер
- `npm run lint` - Проверить код
